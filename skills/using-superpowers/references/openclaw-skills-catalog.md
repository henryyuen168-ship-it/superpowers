# OpenClaw Skills Catalog

Use this reference when you need a quick inventory of the current OpenClaw skill surface.

## Core installed Superpowers-derived workflow skills

- `brainstorming` — design refinement before implementation
- `writing-plans` — detailed implementation plans
- `test-driven-development` — RED/GREEN/REFACTOR implementation discipline
- `systematic-debugging` — structured root-cause workflow
- `verification-before-completion` — verification gate before claiming done
- `subagent-driven-development` — implementation with delegated task/review flow

## Additional local review/planning helpers

- `brainstorm-lite` — lighter-weight design gate for small scoped work
- `spec-reviewer` — requirement-compliance review before code-quality review
- `plan-writer` — bite-sized task decomposition helper
- `skill-creator` — create or improve skills in OpenClaw

## Choosing quickly

- Need design first? → `brainstorming` / `brainstorm-lite`
- Need a plan? → `writing-plans`
- Implementing behavior? → `test-driven-development`
- Debugging a failure? → `systematic-debugging`
- Verifying before claiming success? → `verification-before-completion`
- Delegating multi-step implementation? → `subagent-driven-development`
- Unsure which workflow skill applies? → `using-superpowers`
